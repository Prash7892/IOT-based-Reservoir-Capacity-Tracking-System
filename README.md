# Reservoir Capacity Tracking System | IoT-Based Mini Project

Reservoir Capacity Tracking System, an Arduino-based system designed to monitor water levels and provide an alert when the reservoir reaches a critical/full level.

### 🔧 How it works:

1. An ultrasonic sensor measures the water level inside the reservoir. 
2. The Arduino UNO processes the sensor readings. 
3. A 16×2 LCD displays the water level percentage in real time. 
4. When the water level reaches 90% or above, the system triggers a buzzer alert and displays “Tank Full”.
 
### 🛠️ Technologies & Components Used
 
1. Arduino UNO 
2. Ultrasonic Water-Level Sensor
3. 16×2 LCD Display
4. Buzzer
5. Li-ion Battery
6. Jumper Wires
7. Prototype Reservoir/Tank 
 
### 🎯 Objective
 
The main objective of this project is to prevent water overflow and enable simple real-time monitoring of reservoir capacity. The concept can be further developed into a smart water-management system with automatic pump control, mobile notifications, IoT monitoring, and data logging.
This project helped us gain practical experience in Arduino programming, sensors, embedded systems, circuit interfacing, and real-time monitoring.
